argument-hint: <id del hito, ej. M2>

Vamos a trabajar el hito $ARGUMENTS.

1. Lee `CLAUDE.md`, la sección del hito $ARGUMENTS en `docs/PLAN.md` y las secciones de `docs/ESPECIFICACION.md` que ese hito referencia. Si el hito toca autenticación, diagnóstico o manejo de errores, lee también `docs/APRENDIZAJES.md` completo.
2. Revisa el estado actual del código relacionado con el hito.
3. Propón un plan concreto:
   - archivos a crear o modificar;
   - funciones o clases principales con su firma;
   - tests que escribirás, uno por comportamiento;
   - cómo verificarás cada criterio de aceptación.
4. Señala cualquier ambigüedad o decisión que no esté documentada, y pregúntame.
5. **No escribas código todavía.** Espera mi aprobación del plan.
