# p6-eppm-rest-cli

Cliente de terminal, de **solo lectura**, para la API REST de Oracle Primavera P6 EPPM.

> 🚧 **En desarrollo.** Este README se completa en el hito M9 del [plan](docs/PLAN.md).

## Qué hará

- Guardar varios ambientes de P6 y elegir uno con menús de flechas.
- Contraseñas en el almacén de credenciales del sistema operativo, nunca en archivos del proyecto.
- Prueba de conexión con diagnóstico que explica la causa exacta de un fallo.
- Consultar cualquier endpoint GET, ver resultados en tabla y exportarlos a CSV o JSON.
- Lecturas masivas por lotes y series temporales del servicio Spread.
- Las mismas operaciones como comandos, para automatizar.
